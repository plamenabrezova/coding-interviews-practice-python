## 🪣 Stack

---

 - Works on the principle: "**First in, last out**" (FILO). 
 - An item can be inserted and removed from a stack only from one side. 
 - It supports three operations:
   - **insert** (or "push"): putting an item into the (back) stack 
   - **peek**: look at the top item of the stack (the last inserted item that's not removed). 
   - **remove** (or "pop"): remove the last of the stack (back)

---

- In **Python**, you can use the default `list` as a stack since all python lists are dynamically sized.
- In **Java**, you can use an `ArrayList` for this purpose (Java has a built-in `Stack class`, slower than `ArrayList`).
